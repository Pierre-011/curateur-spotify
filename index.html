Connexion à GitHub

Device Flow

Connecte ton compte GitHub pour charger et sauvegarder tes placements dans ton dépôt privé. Tu n'as pas besoin de créer un Personal Access Token.

Comment fonctionne la connexion ?

  1. Clique sur le bouton de connexion.
  2. Le site te fournira un code temporaire.
  3. Ouvre la page officielle de vérification GitHub.
  4. Saisis le code et autorise l'application.

Ouvrir GitHub pour autoriser

Saisis le code uniquement sur le site officiel github.com. Ne le communique à personne.

Sauvegarde & restauration

Exporte une copie JSON pour conserver une sauvegarde indépendante ou restaurer tes données.

Configuration

  1. Utilise un dépôt privé pour tes données.
  2. Installe ton application GitHub sur ce dépôt.
  3. Accorde uniquement les permissions nécessaires.
  4. Active GitHub Pages pour héberger le site.

Les données du catalogue sont stockées dans le dépôt GitHub. Un dépôt privé limite leur consultation aux personnes autorisées.

La connexion est gérée dans le navigateur. Ne place jamais de Client Secret ni de clé privée dans le code de GitHub Pages.
