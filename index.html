Connexion au dépôt GitHub

Sans API Spotify

Le site lit et enregistre tes données dans un fichier JSON de ton dépôt. La connexion est mémorisée dans ce navigateur pour éviter de ressaisir le jeton. Le jeton est stocké dans le stockage local du navigateur, jamais dans le dépôt GitHub.

Crée un jeton limité à ce dépôt, avec le droit Contents: Read and write . Ne le partage jamais. Évite un jeton à portée de tous tes dépôts.

Sauvegarde & restauration

Exporte une copie JSON pour conserver une sauvegarde indépendante ou la restaurer sur un autre dépôt.

Configuration conseillée

  1. Crée un dépôt privé pour les données.
  2. Crée un jeton finement limité à ce dépôt.
  3. Connecte chaque appareil depuis cette page.
  4. Active GitHub Pages sur le dépôt du site.

Les fichiers JSON ne contiennent pas de secret. Le dépôt de données doit rester privé si tu ne veux pas rendre tes informations publiques.
